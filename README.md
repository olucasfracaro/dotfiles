# dotfiles
Aqui você encontra as *dotfiles* que uso no meu [Fedora](https://fedoraproject.org/workstation/).

## O que está incluso?
- **Terminal:** [kitty](https://github.com/kovidgoyal/kitty)
- **Shell:** [zsh](https://zsh.org/)
- **Prompt do shell:** [Starship](https://starship.rs)
- **Editor de texto:** [Neovim](https://neovim.io) + [NvChad](https://nvchad.com) (framework)

### Outros
- [fastfetch](https://fastfetch.dev/)
- [neofetch](https://github.com/dylanaraps/neofetch)
- [glow](https://github.com/charmbracelet/glow)
- [tmux](https://tmux.app)
- [thefuck](https://github.com/olucasfracaro/thefuck) (minha fork com suporte ao Python 3.12)

## Como usar

Para usar **todas** as minhas dotfiles, apenas execute:
``` bash
git clone https://www.github.com/olucasfracaro/dotfiles ~/.config
```
